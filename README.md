# Meeting Floor — アプリとして配布する手順

このフォルダをそのまま静的ホスティングに置けば、スマホのホーム画面から起動する
アプリ（PWA）になります。ビルド作業もアプリストア審査も不要です。

```
meeting-floor-app/
├── index.html                  アプリ本体（これ1枚で全機能が動く）
├── manifest.webmanifest        アプリ名・アイコン・起動方法の定義
├── sw.js                       オフライン起動用（Service Worker）
├── icons/                      ホーム画面アイコン
└── functions/api/generate.js   AI生成のプロキシ（使う場合のみ）
```

---

## フレーズの出し方（2つの入口）

「新しい場面」画面には、役割の異なる入口が2つあります。

| 入口 | 操作 | 出力 | 必要なもの |
|---|---|---|---|
| **内蔵フレーズから選ぶ** | プルダウンで16グループ（仮説・前提、反論 など）から選び「表示」 | そのグループの**全フレーズ**（18〜19件） | なし（オフライン可） |
| **任意の場面をAIで生成** | 場面を入力して「生成」 | AIが生成した**10件**（内蔵フレーズは使わない） | APIキー・通信 |

内蔵グループは最初から全件を表示するため「もっと追加」はありません。
AI生成のセットは「もっと追加」で、重複しない10件をAIが追加します。

---

## 学習済みフレーズの連続再生

「学習済みフレーズ」画面の上部で、覚えたフレーズを **日本語 → 英語** の順に続けて読み上げます。

- 日本語のあと約1.5秒の間を置きます（英語を思い出す時間）。その間、画面の英語は伏せています
- 🔁 リピートをONにすると、最後のフレーズのあと最初に戻ります
- 英語は設定の速度・地域（US/UK）で、日本語は標準速度で読み上げます

**iPhoneでの注意：** iOSは画面ロックやアプリ切替で読み上げを止めます。再生中は画面が自動で消えないようにしています
（Safari 16.4以上。ホーム画面に追加したアプリではiOS 18.4以上）が、手動でロックしたり別のアプリへ移ったりすると止まります。
その場合は一時停止になるので、戻ってから「続きから再生」を押してください。

## ⚠ 先に読む — ホーム画面に「Claude」が追加されてしまう場合

チャット画面に表示されているプレビューは、**アプリ自身のURLを持っていません。**
Claudeの画面の中に埋め込まれて動いているだけなので、その状態で「ホーム画面に追加」すると、
追加されるのは外側のページ（claude.ai）です。だからClaudeが起動します。

正しい手順は次の3つです。**この順番でしか成立しません。**

1. `meeting-floor-app` フォルダをダウンロードする
2. HTTPSのどこかに置いて、**このアプリ専用のURL**を手に入れる（下記「1. 置く」）
3. **そのURL**をiPhoneのSafariで開いて、共有ボタン →「ホーム画面に追加」

判別の目安として、追加する前にSafariのアドレスバーを見てください。
`claude.ai` のままなら追加してはいけません。`〜.pages.dev` など自分のURLになっていればOKです。

間違えて追加してしまったアイコンは、長押し →「ブックマークを削除」で消せます。

なお、LINEやSlackなどアプリ内のブラウザで開くと「ホーム画面に追加」自体が出ません。
必ずSafariで開いてください。

## 0. いますぐ試す（PCとスマホが同じWi-Fiにある場合）

置く前に手元で確認したいときだけ。PCでこのフォルダに入り、

```
python3 -m http.server 8000
```

PCのローカルIP（macOS: `ipconfig getifaddr en0` / Windows: `ipconfig`）を調べ、
スマホのブラウザで `http://<PCのIP>:8000/` を開きます。

ただしこの方法は HTTP なので **録音は使えません**（ブラウザの仕様でHTTPS必須）。
ホーム画面への追加もできません。本番はこの下の手順で置いてください。

## 1. 置く（所要5分・無料）

> Cloudflare や Netlify を使いたくない場合は、**「SETUP-iphone-only.md」** を参照してください。
> GitHub Pages なら PC なしで完結します（サブディレクトリ配信でも動作確認済み）。

HTTPS で配信されることだけが条件です。以下のいずれか。

| 手段 | 手順 | AI生成 |
|---|---|---|
| **Cloudflare Pages** | ダッシュボード → Create → Pages → このフォルダをドラッグ＆ドロップ | 使える |
| Netlify Drop | `app.netlify.com/drop` にフォルダをドロップ | 別途対応が必要 |
| GitHub Pages | リポジトリに置いて Settings → Pages を有効化 | 使えない |
| Vercel | `vercel` CLI を実行 | 使える（後述） |

AI生成まで使うなら **Cloudflare Pages** を選んでください。静的配信とサーバー関数が
同じ場所で動き、`functions/api/generate.js` がそのまま有効になります。

## 2. ホーム画面に追加する

- **iPhone / iPad**: Safari で開く → 共有ボタン（□に↑）→「ホーム画面に追加」
  - Chrome や他ブラウザからは追加できません。Safari で開いてください。
- **Android**: Chrome で開く → メニュー →「アプリをインストール」
- **PC**: アドレスバー右のインストールアイコン

追加するとアドレスバーが消え、単独アプリとして起動します。
アプリ内のホーム画面に、いまの状態に応じた追加手順が表示されます。

## 3. AI生成を有効にする（任意）

方法は2つあります。**GitHub Pages など静的配信しかできない場所では方法Bを使います。**

### 方法A: サーバー側にキーを置く（Cloudflare Pages / Vercel）

推奨。キーがブラウザに一切渡らないため最も安全です。

未設定でも**内蔵の300フレーズ**で全機能が動きます。場面に応じた新規生成まで
欲しい場合だけ設定してください。

1. Cloudflare Pages の Settings → Environment variables に
   `ANTHROPIC_API_KEY` を登録する
2. `index.html` 内の1行を書き換える

```js
const AI_CONFIG = {
  proxyEndpoint: '/api/generate',   // ← null から変更する
```

APIキーはサーバーの環境変数にだけ置かれ、配信されるコードには含まれません。
**ブラウザ側のコードにキーを書くと、開発者ツールで誰でも読めます。絶対に書かないでください。**

Vercel を使う場合は `functions/api/generate.js` を `api/generate.js` に移し、
ファイル末尾のコメントにある形へ書き換えてください。

### 方法B: 端末にキーを置く（サーバー不要・GitHub Pages でも動く）

アプリの「設定・データ → AI生成」に、**APIキーを貼り付けて保存するだけ**です。
事業者の選択もモデル名の入力も不要です。

| 貼ったキー | 判定される事業者 | 自動選択されるモデル | 生成1回の目安 |
|---|---|---|---|
| `sk-…` / `sk-proj-…` | OpenAI（ChatGPT） | 一覧から最も安い現行モデル | 約0.5円 |
| `sk-ant-…` | Anthropic（Claude） | 一覧から最も安い現行モデル | 約2円 |

キーの先頭で事業者を判定し、その事業者のモデル一覧を照会して最も安い現行モデルを自動で選びます。
モデル名は随時改廃されますが、**生成時に弾かれた場合も自動で選び直して再試行する**ため、
利用者側の操作は不要です。別の事業者のキーを貼り直せば、そのまま切り替わります。

**この方式で守られていること****この方式で守られていること**

- キーは**この端末の中だけ**に保存されます。公開リポジトリには一切含まれません
- 学習データの書き出しJSONにも含まれません（別枠で保存しているため）
- 送信先はAnthropicのAPIのみ。外部スクリプトやCDNは一切読み込みません
- キーが無効・通信不能のときは生成失敗を明示します（内蔵フレーズで代替はしません）

**この方式のリスク**

- 端末を他人が触れる状態だと、保存領域からキーを読み出される可能性があります
- **共用のPCやタブレットでは使わないでください**
- 端末を紛失した場合は console.anthropic.com でキーを失効させてください
- 不安があれば方法Aを選んでください

自分専用のiPhoneで使う限りは、Anthropicが想定している
「利用者が自分のキーを持ち込む」使い方に沿った構成です。

## 4. 費用

**AIを使わなければ完全に無料です。** 内蔵の300フレーズで、カード学習・瞬発テスト・復習管理まで全機能が動きます。

| 項目 | 費用 | 備考 |
|---|---|---|
| ホスティング（Cloudflare Pages） | 0円 | 静的ファイルの配信は無料・無制限。クレジットカード不要 |
| ホーム画面への追加・オフライン動作 | 0円 | 端末の機能 |
| 読み上げ（US / UK） | 0円 | 端末内蔵の音声を使用 |
| 録音・再生 | 0円 | ブラウザの機能。データは端末内のみ |
| 学習データの保存 | 0円 | 端末内のみ。サーバー費用は発生しない |
| APIプロキシの実行 | 実質0円 | Cloudflare の無料枠は1日10万リクエスト。個人利用では到達しない |
| **AIによるフレーズ生成** | **従量課金** | 下記 |

### 使用するAIを選ぶ

「設定・データ → AI生成 → 使用するAI」で **Anthropic（Claude）** と **OpenAI（ChatGPT）** を切り替えられます。
プロンプトと検証は共通で、リクエストの組み立て方だけが変わります。

| 事業者 | 既定モデル | 単価（入力/出力・100万トークン） | 生成1回の概算 |
|---|---|---|---|
| Anthropic | claude-haiku-4-5 | $1 / $5 | 約2円 |
| OpenAI | gpt-5.6-luna | $0.20 / $1.20 | 約0.5円 |

キーは**事業者ごとに別枠で保存**されるため、切り替えても他方のキーは消えません。
どちらも端末内のみの保存で、書き出しJSONには含まれません。

### AI生成のコスト目安

Anthropic APIは従量課金で、無料枠はありません（新規登録時に少額の無料クレジットが付きます）。
公式レート → https://platform.claude.com/docs/en/about-claude/pricing

| モデル | 入力 / 出力（100万トークンあたり） | 生成1回（10フレーズ）の概算 |
|---|---|---|
| Claude Haiku 4.5（既定） | $1 / $5 | 約2円 |
| Claude Sonnet 5 | $2 / $10 | 約4円 |

概算は入力1,500・出力2,500トークン、1ドル150円での試算です。実際のトークン数は
場面や既出フレーズの量で変動します。

つまり **100回生成しても200〜400円** 程度です。新規登録時の無料クレジットだけでも
数百回はまかなえます。使いすぎが不安なら、Claude Consoleで利用上限を設定できます。

より安く抑えたい場合は、既定のHaiku 4.5のまま使ってください。
定型表現の生成という用途では品質差が出にくく、コストは半分です。

## 5. 更新するとき

`index.html` を差し替えたら、**`sw.js` の `CACHE` の版番号を必ず上げてください。**

```js
const CACHE = 'meeting-floor-v2';   // v1 → v2
```

上げないと、端末に残った古い版が表示され続けます。

## 他の人にURLを渡すとき

**学習データは利用者ごとに完全に独立します。** サーバーもデータベースも無く、
保存先は各自のブラウザの localStorage だけなので、誰かが生成したフレーズや
習熟状態が他の人に見えることはありません。同じURLを何人に渡しても干渉しません。

ただし次の2点は仕組み上の例外です。

### 1. 同じ端末の同じブラウザを共有すると混ざる

データはブラウザ単位です。1台のPCやタブレットを複数人で使い、同じブラウザ・
同じプロファイルで開くと、**学習履歴も復習スケジュールも共有されます。**
分けたい場合はブラウザのプロファイルを分けるか、別の端末を使ってください。

### 2. 同一オリジンの他ページからは読める

localStorage はパスではなく**オリジン単位**（`https://ユーザー名.github.io` 全体）です。
`/meeting-floor/` に置いても、同じ `ユーザー名.github.io` に置いた別のページから
このアプリのデータを読み出せます。

自分のリポジトリだけを置いているなら問題ありませんが、
**APIキーを登録した状態で、同じGitHubアカウントに他人が作ったページを公開するのは避けてください。**
APIキーを他人にも使わせたくない場合は、そもそも配布用のURLにはキーを登録せず、
各自に自分のキーを入れてもらってください（キーは端末ごとの保存です）。

### 確認済みの挙動

| 状況 | 結果 |
|---|---|
| 別の端末・別のブラウザ | 完全に独立 |
| 同じブラウザの別タブ | 同じデータ（同一利用者として扱われる） |
| 同じオリジンの別パス | データを共有する |
| 学習データの外部送信 | 無し（通信先は Anthropic API のみ） |

## 動作条件と制約

| 機能 | 条件 |
|---|---|
| 画面 | iPhone SE(320px)〜iPad・横向きまで確認済み |
| カード学習・瞬発テスト | オフラインで動作 |
| 読み上げ（US / UK） | 端末の音声を使用。オフライン可。iOS は初回だけ画面タップが必要 |
| 録音 | **HTTPS 必須**（ファイルを直接開くと使えません） |
| AI生成 | 通信とAPIキーが必要。失敗時はエラーを表示（内蔵フレーズで代替しない） |

**学習データはこの端末の中だけに保存されます。** サーバーには何も送られません。
ブラウザのデータ削除、iOS のストレージ整理、機種変更で消えるので、
アプリ内の「書き出す（JSON）」でときどきバックアップしてください。
読み込みは同じ画面の「読み込む」から行えます。

## アプリストアに出したい場合

PWA と違い、費用と審査が発生します。個人利用なら不要です。

1. Capacitor で包む — `npx cap init` → `npx cap add ios` → `www/` にこのフォルダを置く
2. Apple Developer Program（年 99 USD）／ Google Play（初回 25 USD）に登録
3. 審査に出す

Apple は「Webサイトを包んだだけ」のアプリを Guideline 4.2（最低限の機能）で
リジェクトすることがあります。審査を通す必要が本当にあるか、先に確認してください。
